# Sharing an experience, not just a render

## Make the promise obvious

Design a moment that reads without sound: an action, a visible response and a striking view of the same implemented place. A practical capture hypothesis is a short 10–20 second sequence: recognizable place → one action → payoff → owner/project identity and a usable URL. Adjust pacing to the content; this is not a platform algorithm claim.

If a launch or media kit is requested, deliver actual-browser stills and a short clip, with wide and vertical compositions where relevant. Reframe the camera and caption safe areas instead of mechanically cropping away the action. Use accurate owner attribution, captions/alt text and an honest description of what visitors can do. Do not label a concept render as gameplay. Never invent visitor numbers, press attention or performance results.

Optimize discoverability, immediate comprehension, real agency and repeatable capture. These are design choices, not evidence of a specific month's virality. Verify current platform specifications when publishing; do not hardcode supposed trending tactics into a timeless skill.

## Connect curiosity back to the website

- Give the world a stable canonical URL and a clearly named main-site return link on entry and pause.
- Add Open Graph title, description, URL, type and a real preview image in server-rendered/static HTML; social crawlers may never run WebGL.
- If sharing a place/action, encode only a validated station identifier or bounded public state. Resolve unknown or obsolete IDs to a safe arrival point. Do not replay private state or arbitrary script/coordinates from a URL.
- Let a shared link open a friendly preview with an explicit enter action. Avoid surprise pointer lock, audio, download or login.
- Use the native share API only if available and user-triggered; offer a copyable link if absent or sharing fails. Cancellation is not an app error.
- Make reading and exploration alternatives obvious. Novelty should lead to the owner's actual work, not trap visitors in the demo.
- Add analytics only within the site's existing consent/privacy choices. Event names can distinguish entry, first interaction, content open and return; no tracking system is required to make the world shareable.

## Evidence packet

Keep it proportional: one chosen direction, a route map, source-coverage results, representative screenshots, interaction regression results, measured performance conditions and the capture sequence if requested. Reuse repository evidence conventions. Do not force a new documentation tree on each user's project.

Record what was **designed**, **implemented**, **browser-verified** and **independently playtested**. Each stronger label needs stronger evidence. A headless smoke pass checks boot behavior; a graph pass checks authored references. Neither establishes that a first-time visitor found the world delightful.

Primary references: [Open Graph](https://ogp.me/) and [Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share). Check current support/specifications at release time.
